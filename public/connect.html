How to start it

If the address bar contains the word Temp or .zip, you are still inside the zip. Close that window. Right-click the zip in Downloads → Extract All.
Download the zip
1. Close the zip window Do not run files from inside it.
2. Downloads → right-click the zip → Extract All → Extract That puts a real folder on your PC. Look for MT5-Demo on the Desktop or in Downloads.
3. Open MetaTrader 5 and log into Demo Leave MT5 open.
4. In the extracted folder, double-click DOUBLE-CLICK-ME If Windows warns you, click More info → Run anyway. Leave the black window open.
5. Refresh the website Demo should say Live and show your login. The files live at C:\Users\YourName\MT5-Demo after it starts.
