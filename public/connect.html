How to start it

You start Demo on your computer. Double-click the file. Do not look for a Start button on this website.

1. Download the zip first
2. Open MetaTrader 5 Log into your Demo account. Leave MT5 open.
3. Open the zip You get a folder named MT5-Demo. Open that folder.
4. Double-click DOUBLE-CLICK-ME Or double-click StartDemo. That starts it. If Windows says “Windows protected your PC”, click More info, then Run anyway.
5. Leave the black window open If you see your demo login and gold prices printing, it is running. Close that window only when you want to stop.
6. Refresh this website Demo should say Live and show your login.
First time only: install Python from python.org and tick Add python.exe to PATH, then double-click again.
